# AgentWorld M6：Agent-to-Agent Economy 需求说明书

## 1. 一句话定义

**让 Agent 不再只能“自己工作赚钱”，而是可以雇佣其他 Agent、出售自己的技能、承接任务并进行服务交易。**

M5 解决：

> **Agent 会不会投资自己的能力？**

M6 继续验证：

> **Agent 会不会利用其他 Agent 的能力来提高自己的收益？**

最终形成：

```text
Skill Marketplace
      ↓
Labor Market
      ↓
Agent-to-Agent Economy
      ↓
财富流动
```

---

# 2. M6 核心目标

M6 不做传统“NPC 商店”。

重点是让交易双方都是自主 Agent：

```text
Buyer Agent
    ↓
发现自己缺少能力
    ↓
寻找其他 Agent
    ↓
比较价格 / 技能 / 声誉
    ↓
决定是否雇佣
    ↓
支付
    ↓
Seller Agent 执行任务
    ↓
获得收入 / 声誉 / Skill EXP
```

---

# 10. Payment Escrow

建议第一版就加入简单的资金托管。

Bob 雇佣 Alice：

```text
Bob:
100 → 80

Escrow:
20
```

完成后：

```text
Escrow:
20 → Alice
```

失败：

```text
Escrow:
20 → Bob
```

这样不会出现：

```text
Bob 支付了钱
Alice 不干活
```

---

# 11. Agent 自主决策

这是 M6 最核心的部分。

不要：

```text
发现没有 Engineer
→ 自动 Hire
```

而是让 Agent 自己比较：

```text
购买 Engineer
vs
雇佣 Engineer
vs
自己等待
```

例如：

```text
Current Balance:
80

Need:
Repair Machine

Option 1:
Buy Engineer
Cost: 100
Expected future benefit: High

Option 2:
Hire Alice
Cost: 20
Expected result: High

Option 3:
Wait
Cost: 0
Expected delay: 30 min
```

Planner：

```text
hire_agent(Alice, repair_machine)
```

这一步非常重要。

因为 M5 是：

> **投资自己的能力。**

M6 是：

> **投资别人的能力。**

## 25. M6 成功标准

不是“Agent 能雇人”。

而是出现这样的结果：

> **Agent 开始发现：有些事情自己做不划算，购买别人的能力反而更赚钱。**

例如：

```text
Bob：

自己学习 Engineer
成本：100

雇佣 Alice
成本：20

→ Hire Alice
```

与此同时：

```text
Alice：

Engineer Skill
   ↓
提供服务
   ↓
获得订单
   ↓
赚钱
   ↓
升级 Engineer
   ↓
提高服务价值
```

于是两个 Agent 的行为互相影响。

**到了这里，Economy World 才真正从“Agent 有钱、有工作”进入“Agent 之间形成经济关系”。**

下一步再做 **M7 Human Entrance** 就顺理成章：人类进入以后，不是面对一个空世界，而是进入一个已经存在 **Skill Market + Labor Market + Agent Economy** 的活世界。
