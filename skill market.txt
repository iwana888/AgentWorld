可以。这个需求我建议不要写成“商城功能需求”，而是写成 **Economy World 的 Skill Marketplace + Agent 自主技能投资系统**。重点放在“技能购买会改变 Agent 后续行为”。

# Economy World — Skill Marketplace 需求说明书

## 1. 项目目标

在 Economy World 中增加 **Skill Marketplace（技能市场）**。

技能不再只是 Agent 的静态属性，而是一种可以被 Agent：

* 发现
* 评估
* 购买
* 学习
* 升级
* 使用
* 出售/提供服务

的经济资源。

系统最终需要验证：

> **当 Agent 面临有限资金和不同收益机会时，是否会自主投资未来能力，并因此改变自己的经济行为。**

核心不是“让 Agent 买技能”，而是观察：

```text
资源有限
   ↓
发现技能
   ↓
评估成本 / 收益
   ↓
自主决策
   ↓
购买 Skill
   ↓
能力变化
   ↓
工作机会变化
   ↓
收入变化
   ↓
再次决策
```

---

# 2. 核心原则

### 2.1 不由系统强制购买

系统不能写死：

```text
余额 > 100
→ 自动购买 Engineer
```

而应该由 Agent 自己决定：

```text
Perception
    ↓
Planner
    ↓
Reasoning
    ↓
Decision
    ↓
buy_skill
```

---

### 2.2 Skill 必须真正影响行为

购买 Skill 后必须产生实际影响。

例如：

```text
Courier
```

只能：

```text
Deliver Package
```

购买：

```text
Engineer
```

以后才能看到：

```text
Repair Machine
Repair Factory
Maintain Equipment
```

否则 Skill Marketplace 只是一个 UI。

---

### 2.3 Skill 是经济资源

Skill 应该具有：

```text
购买成本
使用价值
稀缺程度
等级
收益能力
市场需求
```

# 5. Skill Level

Skill 支持等级。

例如：

```text
Engineer Lv1
Engineer Lv2
Engineer Lv3
Engineer Lv4
Engineer Lv5
```

不同等级对应不同能力。

例如：

```text
Engineer Lv1
→ Repair Machine

Engineer Lv2
→ Maintain Factory

Engineer Lv3
→ Repair Reactor

Engineer Lv4
→ Complex Engineering

Engineer Lv5
→ Engineering Contract
```

等级越高：

```text
可执行任务更多
任务收益更高
服务价格更高
```

# 10. Skill 对工作系统的影响

这是整个需求最重要的一部分。

Job 必须声明 Skill Requirement。

例如：

```text
Job: Repair Machine

Required Skill:
Engineer Lv1

Reward:
35 coins
```

另一个：

```text
Job: Repair Reactor

Required Skill:
Engineer Lv3

Reward:
80 coins
```

Agent 只有满足条件才能执行。

因此：

```text
Skill
 ↓
Job Eligibility
 ↓
Job Selection
 ↓
Income
```

真正形成经济闭环。

---

# 11. Skill 收益计算

每个 Job 可以根据 Skill Level 调整收益。

例如：

```text
Base Reward = 30
```

Engineer：

```text
Lv1 → 30
Lv2 → 36
Lv3 → 45
Lv4 → 60
Lv5 → 80
```

这样 Agent 会发现：

> 升级 Skill 本身也是一种投资。

# 13. Skill 稀缺性

系统统计：

```text
Skill Owners
Skill Demand
Skill Jobs
Skill Average Income
```

例如：

```text
Researcher

Owners: 1
Demand: High
Average Income: 65
```

市场可以计算：

```text
Scarcity
```

基本公式：

```text
Scarcity =
Demand / NumberOfOwners
```

稀缺 Skill 可以成为高价值能力。

# 14. Skill 市场价格

第一阶段建议：

**固定价格。**

例如：

```text
Engineer = 100
Doctor = 120
Miner = 80
```

第二阶段再增加动态价格：

```text
Demand ↑
→ Price ↑

Demand ↓
→ Price ↓
```

这样最终可能形成：

```text
Skill Supply
      ↓
Skill Demand
      ↓
Market Price
      ↓
Agent Decision
```

# 18. 失败与风险

不要保证 Agent 买 Skill 后一定赚钱。

例如：

```text
Alice
Balance: 100

购买 Engineer
Balance: 0

但是：

Engineer Jobs:
0
```

可能导致：

```text
收入下降
现金流危机
重新选择工作
出售资产
寻找雇主
借款
```

这非常重要。

因为只有存在失败：

> **Agent 的决策才真正有意义。**

# 22. 第三阶段：真正的 Agent Economy

最终形成：

```text
                 ┌──────────────┐
                 │ Skill Market │
                 └──────┬───────┘
                        │
                    Purchase
                        │
                        ▼
┌─────────┐       ┌──────────┐
│  Agent  │───────▶│   Skill  │
└────┬────┘       └────┬─────┘
     │                 │
     │                 ▼
     │              New Jobs
     │                 │
     ▼                 ▼
  Decision ────────▶ Income
     ▲                 │
     │                 ▼
     └──────────── Wealth
```

最终 Economy World 就不只是：

> **20 个 Agent 在模拟打工。**

而是：

> **20 个拥有不同能力、资源、目标和风险偏好的 Agent，在同一个有限资源世界里，自主进行职业投资、劳动、交易和竞争。**

这时候 **Skill Marketplace 会成为 Economy World 的核心实验设施，而不是一个附属功能。**
