Pascal World · Research

Does experience change behavior?

One agent. Five issues. Each solved by writing, compiling and testing real Pascal — against a real compiler. We measured Cold vs Warm. Memory retrieval went 1 → 21. Behavior barely moved. That null-ish result is the finding.

Next Research Question

From remembering to learning.

Today the loop is: experience becomes memory, memory becomes context. We have proven that. What we have not proven is the last step — that experience changes the decision.

When does experience actually change what an agent does?

Not a feature sprint. Pascal World is the lab. Group A has no memory, Group B has raw history, Group C has operational memory — Problem · Action · Failure · Cause · Resolution — the kind that prescribes an action, not just a fact. Same agent, same issues, same FPC, same budget.
